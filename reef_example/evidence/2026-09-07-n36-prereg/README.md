## 预测

1. **有效 n ≈ 25。** 上一轮 12 步共 108 对,丢掉平局后剩 75,平局率 31%。
   36 x 0.69 ≈ 25。若实测 n 明显低于 20,说明平局率随题数上升 —— 那本身是结果。

2. **符号检验的门槛从"一场不能输"降到"允许输约 8 场"。** n=25 时 alpha=0.10
   需要约 17 胜(68%)。

3. **基线这轮会出现非零的发布。** 上一轮 12 步 0 发布,唯一原因是 n 太小;若 n=25
   仍然 0 发布,那就不是样本量问题,而是候选**真的**没有稳定优势 —— 那会把论文的
   说法再推一层:自进化循环在这个域根本没有可发布的改动。

4. **两把闸门的分歧会减少。** 上一轮 4/12(33%)。n 变大后 `wins > losses` 与符号
   检验会更常同意;若分歧率不降,说明差异不是样本量造成的。

## 怎么算预测错

- n 落在 20–30 之外 -> 第 1 条错
- 基线仍 0 发布 -> 第 3 条错(而这比对了更有价值)
- 分歧率 >= 33% -> 第 4 条错
